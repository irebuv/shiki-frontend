# Shiki Frontend

Web UI for the Shiki project.

Stack
- React + TypeScript
- Vite
- Tailwind CSS

Quick start (Docker)
1) From repo root:
   docker compose up -d frontend
2) Open http://localhost:5175

Local (no Docker)
1) npm install
2) npm run dev
3) Open http://localhost:5175

Build
- npm run build
- npm run preview
